# 🎓 Varmala - Hindi Alphabet Learning

An interactive web-based application designed to teach Hindi alphabet (वर्णमाला) to learners in an engaging and fun way.

## 📋 Features

- **Interactive Alphabet Buttons**: Click on each Hindi letter to see:
  - Letter name with English translation
  - Related word example with Hindi script
  - Corresponding image for visual learning
  - Phonetic pronunciation guide

- **Responsive Design**: 
  - Works seamlessly on desktop, tablet, and mobile devices
  - Beautiful gradient purple background
  - Smooth and intuitive user interface

- **Complete Hindi Alphabet Coverage**:
  - Vowels (स्वर): अ आ इ ई उ ऊ ऋ ए ऐ ओ औ अं
  - Consonants (व्यंजन): Full set including क्ष, त्र, ज्ञ

- **Visual Learning**:
  - High-quality images for each letter example
  - Color-coded buttons (Cyan theme)
  - White card-based content layout

## 🛠️ Technologies Used

- **HTML5**: Structure and semantic markup
- **CSS3**: Modern styling with gradients and responsive design
- **JavaScript**: Interactive functionality and DOM manipulation
- **Bootstrap 5**: Responsive grid system and components

## 🚀 How to Use

1. Open `varmala.html` in your web browser
2. Click on any Hindi alphabet button
3. View the letter name, example word, and corresponding image
4. Learn pronunciation and meaning
5. Explore all letters by clicking through each button

## 📚 Learning Content

Each button displays:
- **Hindi Letter**: Main character
- **Title**: Letter + Example word (e.g., "अ से अनार")
- **English Translation**: Phonetic guide
- **Image**: Visual representation of the example

Example:
```
अ से अनार
(अ - अनार = Pomegranate)
अ = a
```
